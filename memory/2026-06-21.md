## Lessons

- **Confident absence claims are a new failure mode.** AGENTS.md already had a "verify writes" rule for the edit-revert bug. This is a *different* bug: I'm sure something isn't there without checking. The 2026-06-21 channel-history incident is the canonical example.
- **The plan was real, just not on disk.** I had a long architectural conversation on 2026-06-19 and the "plan" existed only as the chat log between us. When I summarized it in 18:31 with "§8, 6 phases, 5 questions," I was citing a plan I had *not persisted*. Bad habit. Plans should land in a file before they get cited, especially if they're going to be referenced later.
- **Operator was right that I should have looked at history.** I had access to it via `message read`. The cost was one tool call. I chose to confidently search the filesystem instead and got it wrong.
